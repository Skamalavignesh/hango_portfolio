4. **Akarshana Gold Company:** FinTech & Gold Valuation Platform.

---

## 🛠️ GitHub Pages Deployment Guide

1. Create a repository on GitHub (e.g., `portfolio`).
2. Add all files into your repository.
3. Open your repository on GitHub and click **Settings** > **Pages**.
4. Set the **Branch** to `main` and **Folder** to `/ (root)`.
5. Click **Save**. Your site will be published live!
